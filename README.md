✊ PANESYSTEM — O Algoritmo na Beleza

Um projeto dedicado a conscientizar, analisar e combater o racismo algorítmico presente em sistemas e filtros de embelezamento digital, promovendo justiça, diversidade e responsabilidade na tecnologia.

📌 Sobre o Projeto

O PANESYSTEM nasce da necessidade urgente de discutir e denunciar como algoritmos de "embelezamento" (presentes em redes sociais, aplicativos de fotos e editores de imagem) reproduzem e reforçam padrões raciais excludentes.

Frequentemente, esses sistemas alteram traços raciais, clareiam peles ou apagam características identitárias de pessoas negras sob a justificativa de "melhoria estética". O projeto busca:

Conscientizar: Educar a sociedade sobre o impacto da inteligência artificial e dos algoritmos na perpetuação de preconceitos estruturais.

Receber Denúncias: Disponibilizar um espaço seguro para que usuários relatem casos de racismo algorítmico vivenciados em plataformas digitais.

Promover Responsabilidade: Cobrar transparência, ética e diversidade no desenvolvimento de tecnologias.

"Numa sociedade racista, não basta não ser racista, é necessário ser antirracista." — Angela Davis

⚙️ Principais Funcionalidades

Apresentação do Projeto: Introdução aos conceitos de racismo algorítmico e viés em inteligência artificial.

Canal de Denúncia: Formulário interativo para envio de relatórios e relatos de exclusão/alteração não consentida por algoritmos.

Acessibilidade Universal (Inclusão Digital): O site foi projetado com foco total em acessibilidade web (WCAG), trazendo uma barra lateral dedicada com:

♿ Suporte a recursos de acessibilidade motora e visual.

🔊 Leitor de tela / Áudio para leitura de conteúdo textual.

🔤 Ajuste e ampliação de tamanho de fonte.

🤟 Tradutor de Libras (VLibras / intérprete digital).

👁️ Modo de alto contraste / ajuste de visualização.

🎨 Layout e Protótipo

A interface utiliza uma paleta de cores forte e consciente (tons de vinho/marrom, preto, branco e bege), combinada com imagens históricas de movimentos de igualdade racial.

🚀 Como Executar o Projeto Localmente

Clone o repositório:

git clone https://github.com/vick090/PANESYSTEM.git

Navegue até a pasta do projeto:

cd panesystem


Abra o arquivo index.html no seu navegador de preferência ou utilize a extensão Live Server no VS Code.
